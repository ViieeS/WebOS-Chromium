# Ubuntu 22.04 (jammy) armhf packages for the target sysroot: headers, crt files, .pc files and link stubs.
# Why jammy: its glibc is 2.35, the same version as the TV, so headers, crt*.o, libc_nonshared.a and libc.so agree.
# Every shared library that also exists on the TV is then REPLACED by the TV's own file (build-sysroot.sh step 4),
# so Chromium links against exactly what the TV has. One package per line; '#' starts a comment.
# If gn gen or the build says "Package X was not found" or "fatal error: foo.h not found", add the -dev package here,
# and rebuild the sysroot (build_sysroot).
