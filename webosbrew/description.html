Chromium Browser for your LG TV

Chromium with the full Chrome interface, running natively on webOS: tabs, address bar, menus, bookmarks, history, downloads and extensions from the Chrome Web Store. No root needed.

What you get

  • Built for the TV's own processor, display server and GPU driver. No emulation.
  • Pages drawn on the TV's GPU.
  • A sharp 1920x1080 window with the interface at 1.5x.
  • Hardware video decoding on every site, up to 1080p60.
  • The remote's arrows, OK and Back move through pages, menus and tabs. The Magic Remote pointer works as a mouse, and typing uses LG's on-screen keyboard.
  • TV Tools, built in on the toolbar: a video quality limit for any site, TV versions of websites, lite mode, a tab limit and unloading of background tabs.
  • Bookmarks and settings are kept on the TV and survive reboots.

Which TVs

webOS 4.4 (2018-2019 models) and newer. Check Settings > Support > TV Information > webOS TV Version. On older TVs the app shows a message and closes.

Moving from the old Chromium app

Chromium (old), org.nativechromium.browser, gets no more updates. Open it once after its last update (0.0.67), then install Chromium Browser: your bookmarks and history come over by themselves. Saved passwords and site logins don't move. Then remove Chromium (old).

No sandbox

Chromium's sandbox can't run in a Developer Mode app (the TV's kernel has no user namespaces or seccomp), so the browser runs without it. All sites share one page process, and the GPU and network code run in the browser process. A page that exploits a bug in Chromium could reach everything the browser holds: cookies and logins for every site, and saved passwords (stored without a system keyring). Keep the browser updated, and think twice before signing in to important accounts or saving passwords on the TV.

TV Tools changes pages

On every site it answers the site's video checks (MediaSource, canPlayType, mediaCapabilities) and removes streams above your quality limit from HLS and DASH playlists, which means it wraps fetch and XMLHttpRequest. In TV mode it sends the webOS TV user agent and hides navigator.userAgentData. It keeps its settings for each site in that site's localStorage (key __tvtools_cfg). If a site misbehaves, turn TV Tools off for that site from its toolbar button.

Good to know

  • Testers have run it on webOS 4.10, 5.5, 5.6, 6.5, 7.6, 8 and 10. How fast it is depends on the model.
  • No Netflix or other DRM video, and no Google account sync.
